# SGDK Skills

Practical agent skills for making Sega Mega Drive and Genesis games with
[SGDK](https://github.com/Stephane-D/SGDK) and the
[SGDK Docker toolchain](https://github.com/ewrogers/sgdk-docker).

The first collection is being developed. Each skill will be independently
installable through `npx skills` and include tested examples and focused references.
